# Frontend source of truth

Canonical Vue SPA repository:

**https://github.com/daotismart/QuantDinger-Vue**

Clone into this backend checkout for local UI work:

```bash
git clone https://github.com/daotismart/QuantDinger-Vue.git QuantDinger-Vue
```

Agents and developers must use that repository for all frontend changes
(router, menus, views, i18n, API clients). Do not treat OpenByteInc/QuantDinger-Vue
as the write target for this deployment.
