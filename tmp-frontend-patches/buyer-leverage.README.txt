Buyer unit real leverage chart (买方单位真实杠杆)

Backend
  GET /api/cn-derivatives/history?chart=options.buyerLeverage
  Panel field: buyer_leverage / month_series[].buyer_leverage
  Formula: (|Δ| × underlying / premium) / |cash_theta|
  cash_theta = unit Black-76 θ × contract multiplier (yuan/day per contract)
