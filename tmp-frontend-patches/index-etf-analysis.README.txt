Index tab shows benchmark-index analysis (point, volume, constituents, weighted PE/margin).
It does NOT attach linked-ETF fund metrics (AUM / fees / IOPV).

Backend

  build_spot_index_panel attaches spot.index via enrich_index_metrics (CSI constituents).
  History: chart=index.metrics|index.price|index.volume → build_index_metrics_history.
