Index tab also shows linked ETF fund share of index constituent cap
and that ETF's option Greek notionals. It still does NOT dump fund-level
AUM / fees / IOPV onto the index panel (no spot.etf).

Share
  share_pct = ETF scale / index constituent_market_cap_sum * 100
  Multiple linked ETFs also get combined_share_pct and etf_group_share_pct.

Greeks + capital (all linked ETFs, all-month options panel)
  delta_notional = portfolio Delta * spot
  gamma_notional = Net GEX (or Gamma * spot)
  vega_notional  = yuan per 1% vol
  theta_notional = yuan per day
  premium_total / margin_total / time_value_total from capital_curve.total
  Top cards are the yuan sum; option_greeks.etfs is the per-ETF breakdown.

Backend
  GET /api/cn-derivatives/spot?scope=etf&picker_kind=spot_index&root=000016.SH&etf=510050
  build_spot_index_panel attaches:
    spot.index.linked_etfs
    spot.index.etf_share
    spot.index.option_greeks
  Options panel cache key etf_options_panel:v3:{code6}:all is cache-only on
  the index *spot* request path (no live build_etf_options_panel there).
  The index tab separately loads GET /options?scope=etf for every linked ETF
  (STAR 50: 588000 and 588080), not only the selected picker code, so
  各ETF分项 lists each option underlying. ETF期权风险数据 stays on the
  selected ETF; 对应期权希腊字母名义资金 is the yuan sum. Live fetches also
  warm the Redis panel cache.
  Index enrich uses cache/DB constituent snapshots (live=False).

  Index tab also loads IH/IF futures + HO/IO options in parallel with spot:
  股指期货期权风险数据 = HO greeks / GEX; 股指期货 = monthly IH;
  股指期货期权 = HO capital. ETF期权风险数据 = selected ETF option greeks/GEX.
  Those sections render as soon as the ETF maps to options / IH/HO.
